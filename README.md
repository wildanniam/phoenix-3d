# Rise Again

An interactive 3D phoenix experience built with React, Vite, React Three Fiber, and a rigged Creative Commons model from Sketchfab.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Interaction

- Scroll to move the phoenix through the story.
- Drag the phoenix for a closer look.
- Use the motion control in the header to pause or resume the wing animation.
- Reduced-motion preferences disable the looping model and ambient particle movement.
